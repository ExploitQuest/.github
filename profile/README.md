# ExploitQuest

**Think. Test. Solve.**

ExploitQuest is a collection of legal hacking challenges across multiple difficulty levels—a place to practice security problem-solving on deliberately provided challenges.

Find a challenge that fits your experience, work through the puzzle, and build your understanding one solution at a time.

Practice stays within each challenge's authorized environment and stated scope.
